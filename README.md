# Solomon Islands Economic Stimulus Package (ESP) Analysis

The Economic Stimulus Package (ESP) in the Solomon Islands was a COVID-19 relief program launched in 2020. 

This project contains the spatial analysis of the ESP grants disbursed in SBDs (Solomon Islands Dollars).
